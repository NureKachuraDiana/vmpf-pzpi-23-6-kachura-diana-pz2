# Цитати дня за категорією

Простий вебдодаток для практичної роботи №2 з дисципліни «Високорівневі мови програмування та фреймворки».

## Функціональність

- завантаження даних з окремого JSON-файлу;
- використання методу `fetch()`;
- перетворення тексту JSON у JavaScript-об'єкт через `JSON.parse()`;
- заповнення випадаючого списку категоріями;
- відображення цитати дня відповідно до вибраної категорії.

## Структура проєкту

```text
.
├── index.html
├── quotes.json
├── README.md
└── .gitignore
```

## Запуск проєкту

Через використання `fetch()` сторінку бажано запускати через локальний сервер.

### Варіант 1: Python

```bash
python -m http.server 8000
```

Після запуску відкрийте сторінку:

```text
http://127.0.0.1:8000/
```

### Варіант 2: VS Code Live Server

1. Відкрити папку проєкту у VS Code.
2. Встановити розширення Live Server.
3. Натиснути правою кнопкою миші на `index.html`.
4. Обрати `Open with Live Server`.

## Основні файли

- `index.html` — структура сторінки, стилі та JavaScript-код.
- `quotes.json` — дані з категоріями та цитатами.
